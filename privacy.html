INFORMATIVA SULLA PRIVACY

SourceMonitor — versione 1.4.0

SourceMonitor non raccoglie e non conserva dati personali per conto del Titolare, e non gliene manda nessuno. Non contiene telemetria, non traccia l'uso, non richiede un account, non mostra pubblicità e non comunica con nessun server del Titolare, in nessuna configurazione.

CHE COSA ESCE DAL TUO COMPUTER

SourceMonitor si collega soltanto agli indirizzi che compaiono nelle liste che gli fornisci tu, e al server di posta che configuri tu. Nient'altro.

  • Per ogni indirizzo delle liste il programma fa una normale richiesta web, come farebbe un browser. Il server che la riceve vede ciò che vede in ogni richiesta web: l'indirizzo IP della tua connessione, l'ora e l'identificativo del programma («SourceMonitor/1.0», modificabile nella scheda Pianificazione). Quali siano questi server lo decidi tu, scegliendo gli indirizzi da sorvegliare; a quello che ne fanno si applica l'informativa di ciascuno di loro.
  • Se attivi gli avvisi via email, il programma invia al server di posta che hai indicato un riepilogo del controllo: quali fonti hanno un problema e perché. Il messaggio parte dal tuo account di posta verso i destinatari che scegli tu.
  • Se scarichi i file delle liste nell'archivio locale, i file arrivano sul tuo computer dagli stessi indirizzi.

CHE COSA RESTA SUL TUO COMPUTER

Tutto ciò che il programma scrive sta nella sua cartella di lavoro (normalmente Documenti\SourceMonitor): le impostazioni, lo storico dei controlli, il registro, i report e l'archivio. Non esce da lì. La password del server di posta non è mai scritta in chiaro: è cifrata con DPAPI, il meccanismo di Windows legato al tuo account, e non è leggibile da un altro utente o da un altro computer. Puoi cancellare tutto in qualunque momento cancellando quella cartella.

ACQUISTO DAL MICROSOFT STORE

Se hai acquistato SourceMonitor dal Microsoft Store, i dati dell'acquisto e del pagamento li tratta Microsoft secondo la propria informativa. Il Titolare non li riceve.

IL CONTENUTO DELLE LISTE

Le liste le scrivi tu, e possono contenere quello che vuoi. Se vi inserisci dati personali — per esempio indirizzi che contengono nomi o credenziali — restano sul tuo computer e nei report, e vengono inviati soltanto ai server che quelle stesse righe indicano. Il consiglio è di non inserirne.

COMPONENTI DI TERZI

Il programma include il runtime Microsoft .NET, i cui testi di licenza viaggiano insieme al programma nella cartella Licenze. Non introduce telemetria in questo prodotto.

PRIVACY POLICY

SourceMonitor — version 1.4.0

SourceMonitor does not collect or keep personal data on behalf of the Licensor, and sends it none. It contains no telemetry, does not track usage, requires no account, shows no advertising and does not communicate with any server of the Licensor, in any configuration.

WHAT LEAVES YOUR COMPUTER

SourceMonitor connects only to the addresses that appear in the lists you give it, and to the mail server you configure. Nothing else.

  • For each address in the lists the program makes an ordinary web request, as a browser would. The server that receives it sees what it sees in any web request: the IP address of your connection, the time and the program's identifier ("SourceMonitor/1.0", which you can change in the Schedule tab). Which servers these are is up to you, since you choose the addresses to watch; what they do with it is governed by each one's own privacy policy.
  • If you turn on e-mail alerts, the program sends a summary of the check to the mail server you specified: which sources have a problem, and why. The message goes from your mail account to the recipients you choose.
  • If you download the files in the lists to the local archive, the files come to your computer from those same addresses.

WHAT STAYS ON YOUR COMPUTER

Everything the program writes is in its working folder (normally Documents\SourceMonitor): the settings, the check history, the log, the reports and the archive. It does not leave from there. The mail server password is never written in clear text: it is encrypted with DPAPI, the Windows mechanism tied to your account, and cannot be read by another user or on another computer. You can delete everything at any time by deleting that folder.

PURCHASE FROM THE MICROSOFT STORE

If you bought SourceMonitor from the Microsoft Store, the purchase and payment data are processed by Microsoft under its own privacy statement. The Licensor does not receive them.

THE CONTENT OF THE LISTS

You write the lists, and they can contain anything you like. If you put personal data in them — for instance addresses containing names or credentials — it stays on your computer and in the reports, and is sent only to the servers those same lines point to. Our advice is not to put any there.

THIRD-PARTY COMPONENTS

The program includes the Microsoft .NET runtime, whose licence texts travel with the program in the Licenze folder. It adds no telemetry to this product.

WAS IHREN COMPUTER VERLÄSST

SourceMonitor verbindet sich nur mit den Adressen, die in den Listen stehen, die Sie ihm geben, und mit dem Mailserver, den Sie einrichten. Mit nichts sonst.

  • Für jede Adresse der Listen stellt das Programm eine gewöhnliche Webanfrage, wie es ein Browser tun würde. Der empfangende Server sieht, was er bei jeder Webanfrage sieht: die IP-Adresse Ihrer Verbindung, die Uhrzeit und die Kennung des Programms („SourceMonitor/1.0“, im Reiter Zeitplan änderbar). Welche Server das sind, bestimmen Sie, indem Sie die zu überwachenden Adressen wählen; was diese damit tun, regelt jeweils deren eigene Datenschutzerklärung.
  • Wenn Sie E-Mail-Benachrichtigungen einschalten, sendet das Programm an den angegebenen Mailserver eine Zusammenfassung der Prüfung: welche Quellen ein Problem haben und warum. Die Nachricht geht von Ihrem Mailkonto an die Empfänger, die Sie wählen.
  • Wenn Sie die Dateien der Listen in das lokale Archiv herunterladen, kommen sie von denselben Adressen auf Ihren Computer.

WAS AUF IHREM COMPUTER BLEIBT

Alles, was das Programm schreibt, liegt in seinem Arbeitsordner (normalerweise Dokumente\SourceMonitor): die Einstellungen, der Prüfverlauf, das Protokoll, die Berichte und das Archiv. Nichts davon verlässt diesen Ordner. Das Passwort des Mailservers wird nie im Klartext gespeichert: es ist mit DPAPI verschlüsselt, dem an Ihr Konto gebundenen Windows-Mechanismus, und kann weder von einem anderen Benutzer noch auf einem anderen Computer gelesen werden. 隐私政策

SourceMonitor — 版本 1.4.0

SourceMonitor 不会代表许可方收集或保存任何个人数据，也不会向许可方发送任何数据。在任何配置下，它都不包含遥测，不跟踪使用情况，不需要账户，不显示广告，也不与许可方的任何服务器通信。

哪些内容会离开你的电脑

SourceMonitor 只连接你提供给它的清单中出现的网址，以及你配置的邮件服务器。除此之外不连接任何地方。

  • 对清单中的每个网址，程序都会像浏览器一样发出一次普通的网页请求。接收请求的服务器能看到的，与任何网页请求相同：你的网络连接的 IP 地址、时间以及程序的标识（“SourceMonitor/1.0”，可在「计划」选项卡中修改）。这些服务器是哪些由你决定，因为要监控的网址是你选择的；它们如何处理这些信息，适用各自的隐私政策。
  • 如果你启用了电子邮件提醒，程序会向你指定的邮件服务器发送一份检查摘要：哪些来源有问题、原因是什么。邮件从你的邮箱账户发往你选择的收件人。
  • 如果你把清单中的文件下载到本地存档，这些文件也来自同样的网址。

哪些内容留在你的电脑上

程序写入的一切都位于它的工作文件夹（通常是 文档\SourceMonitor）中：设置、检查历史、日志、报告和存档。这些内容不会离开那里。邮件服务器的密码从不以明文保存：它使用 DPAPI（与你的 Windows 账户绑定的机制）加密，其他用户或其他电脑都无法读取。你随时可以通过删除该文件夹来删除全部内容。

在 Microsoft Store 购买

如果你是在 Microsoft Store 购买的 SourceMonitor，购买和付款数据由 Microsoft 按照其自身的隐私声明处理。许可方不会收到这些数据。

清单的内容

清单由你编写，可以包含任何内容。如果你在其中写入了个人数据——例如包含姓名或凭据的网址——这些数据会保留在你的电脑和报告中，并且只会发送到这些行本身所指向的服务器。我们建议不要写入此类数据。

第三方组件

本程序包含 Microsoft .NET 运行时，其许可文本随程序一起位于 Licenze 文件夹中。它不会为本产品添加任何遥测。
